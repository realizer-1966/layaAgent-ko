게이트

어느 기준이든 아래로 떨어지면 그 단계는 보류됩니다: System 2가 결정하고, System 2가 없으면 사용자가 결정합니다. 슬라이더를 움직이면 모델 호출 없이 현재 실행과 과제 점수가 즉시 다시 계산됩니다.

메모는 이 브라우저의 IndexedDB에 저장됩니다. 에이전트는 메모 도구로 저장·검색·삭제합니다.

    노드를 클릭하세요: Laya가 답한 타입화된 질문, 선택지마다의 확률, 게이트의 이유, 보류된 단계라면 System 2의 프롬프트와 응답이 보입니다. 점선 마름모는 Laya가 고려한 다음 행동이며, 클릭하면 그 지점부터 다시 실행합니다.

      이 탭의 모든 실행(녹음 재생 포함)을 합친 그래프입니다. 간선은 전이 횟수이고, 노란 테두리는 System 2나 사용자에게 자주 보류된 도구입니다.

      아직 실행이 없습니다.

      현재 실행을 JSON(Laya의 답이 담긴 모든 단계) 또는 RDF Turtle(la:Run과 la:Step, 단계마다 la:decidedBy)로 내려받아 다른 곳에서 SPARQL로 질의할 수 있습니다.
